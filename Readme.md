# ZeusLang 문법 안내서

ZeusLang은 밈 문구를 키워드로 사용하는 간단한 인터프리터 언어다. 숫자는 `아잇`과 `시발!`을 붙여 쓴 이진수이며, 문자열은 Unicode 코드포인트의 나열로 만든다.

## 인터프리터 실행 방법

인터프리터 파일과 실행할 `.zeus` 파일을 지정한다.

```powershell
python interpreter.py 프로그램.zeus
```

예제 프로그램은 다음처럼 실행할 수 있다.

```powershell
python interpreter.py example\helloWorld.zeus
```

정상적으로 실행되면 아래 결과가 출력된다.

```text
Hello World!
```

`python` 명령이 인식되지 않는 환경에서는 Windows Python Launcher를 사용한다.

```powershell
py interpreter.py example\helloWorld.zeus
```

인터프리터는 `.zeus` 파일을 UTF-8로 읽는다. 문법 오류, 선언하지 않은 변수 참조, 0으로 나누기 등이 발생하면 `[ZeusLang 오류]`와 함께 원인과 코드 위치를 표시한다.

## 프로그램의 형태

모든 프로그램은 `안녕하세요`로 시작하고 `아 재밌었다`로 끝난다. 일반 문장(대입, 출력)의 끝에는 `발 존나 기네`를 붙인다.

```zeus
안녕하세요
블블 아잇아잇 발 존나 기네
아 재밌었다
```

위 프로그램은 이진수 `11`, 즉 `3`을 출력한다.

공백과 줄바꿈은 토큰을 구분하는 용도일 뿐, 대부분 문법상 의미는 없다. 단, 이진수는 공백 없이 붙여야 하나의 수로 해석된다.

```text
아잇시발!아잇       → 101(2) → 5
아잇 시발! 아잇      → 숫자 1, 0, 1 세 개로 해석됨
```

## 숫자와 연산

| 의미 | ZeusLang 표기 |
| --- | --- |
| 비트 1 | `아잇` |
| 비트 0 | `시발!` |
| 덧셈 | `모리` |
| 뺄셈 | `후추` |
| 곱셈 | `후쿠하라` |
| 나눗셈 | `이시와타리` |

연산 우선순위는 일반적인 수식과 같다. 곱셈·나눗셈이 덧셈·뺄셈보다 먼저 계산되고, 같은 우선순위에서는 왼쪽부터 계산한다. 괄호와 단항 음수는 현재 지원하지 않는다.

```zeus
안녕하세요
블블 아잇아잇 모리 아잇 후쿠하라 아잇아잇 발 존나 기네
아 재밌었다
```

이는 `3 + 1 * 3`이므로 `6`을 출력한다. 나눗셈 결과는 소수가 될 수 있으며, 0으로 나누면 오류가 발생한다.

## 변수

변수는 숫자 ID로 구분한다. 대입 문법은 다음과 같다.

```text
애송이가? <변수 ID> 제하하핳 <표현식> 발 존나 기네
```

변수를 읽을 때도 `애송이가? <변수 ID>`를 쓴다. 값을 할당하기 전의 변수를 읽으면 오류가 발생한다.

```zeus
안녕하세요
애송이가? 시발! 제하하핳 아잇아잇아잇 발 존나 기네
애송이가? 아잇 제하하핳 애송이가? 시발! 모리 아잇 발 존나 기네
블블 애송이가? 아잇 발 존나 기네
아 재밌었다
```

위 예제는 변수 `0`에 `3`을 넣고, 변수 `1`에 `0번 변수 + 1`을 넣은 뒤 `4`를 출력한다.

## 문자열 출력

출력 키워드는 `블블`이다. 숫자나 표현식을 바로 출력할 수 있고, 문자열은 아래 문법으로 출력한다.

```text
블블 점프를 하고싶으면
  <문자 코드 표현식> 이런이런
  <문자 코드 표현식>
점프킹을 해! 발 존나 기네
```

각 표현식은 하나의 Unicode 코드포인트다. 예를 들어 `H`는 72이므로 `1001000(2)`인 `아잇시발!시발!아잇시발!시발!시발!`로 쓴다.

```zeus
안녕하세요
블블 점프를 하고싶으면
아잇시발!시발!아잇시발!시발!시발! 이런이런
웨얼 이즈 롤백 넷코드? 모리 아잇시발!시발!시발!시발!아잇
점프킹을 해! 발 존나 기네
아 재밌었다
```

이 예제는 `Hi`를 출력한다. 첫 글자 `H`는 절대 코드값으로 적고, 다음 글자 `i`는 `H + 33`으로 계산한다.

### `웨얼 이즈 롤백 넷코드?`

`웨얼 이즈 롤백 넷코드?`는 문자열 안에서만 사용할 수 있으며, 바로 앞 문자의 Unicode 코드포인트를 뜻한다. 같은 글자를 반복할 때는 단독으로 쓸 수 있다.

```zeus
안녕하세요
블블 점프를 하고싶으면
아잇아잇시발!아잇아잇아잇아잇 이런이런
웨얼 이즈 롤백 넷코드? 이런이런
웨얼 이즈 롤백 넷코드? 후추 아잇시발!아잇아잇
점프킹을 해! 발 존나 기네
아 재밌었다
```

위 코드는 `ood`를 출력한다. 첫 `o`(111) 뒤에 이전 문자를 그대로 한 번 쓰고, 마지막 글자는 이전 문자에서 11을 뺀다.

## 조건문

조건문은 `왓 디스 이즈 갈비지 게임?`으로 시작하며, 블록은 `무능한남`과 `도태딜러`로 감싼다.

```text
왓 디스 이즈 갈비지 게임? <왼쪽 표현식> 댄서 <비교 코드> <오른쪽 표현식>
무능한남
  <문장들>
도태딜러
```

조건식은 반드시 `<왼쪽 표현식> 댄서 <비교 코드> <오른쪽 표현식>` 순서로 작성한다. `댄서`는 왼쪽·오른쪽 값을 구분하는 비교 연산자 표식이며, 바로 뒤의 비교 코드는 공백 없이 붙여 쓴 이진수다.

| 코드 | 연산자 | ZeusLang 표기|
| ---: | --- | --- | 
| 0 | `==` | `시발!` |
| 1 | `!=` | `아잇` |
| 2 | `>` | `아잇시발!` |
| 3 | `<` | `아잇아잇` |
| 4 | `>=` | `아잇시발!시발!` |
| 5 | `<=` | `아잇시발!아잇` |

조건이 참이면 `무능한남`과 `도태딜러` 사이의 문장을 순서대로 실행하고, 거짓이면 블록 전체를 건너뛴다. 현재 `else` 문법은 지원하지 않는다. 블록 끝의 `도태딜러` 뒤에는 필요하면 `발 존나 기네`를 하나 붙일 수 있지만, 생략해도 된다.

```zeus
안녕하세요
애송이가? 시발! 제하하핳 아잇아잇아잇 발 존나 기네
왓 디스 이즈 갈비지 게임? 애송이가? 시발! 댄서 아잇시발! 아잇아잇
무능한남
블블 아잇 발 존나 기네
도태딜러
아 재밌었다
```

비교 코드 `아잇시발!`은 `2`이므로, 위 예제는 `3 > 3`을 검사한다. 조건이 거짓이어서 아무것도 출력하지 않는다.

## 반복문

반복문은 `어메이징시발롬`을 사용하며 조건문과 같은 조건·블록 문법을 따른다.

```zeus
안녕하세요
애송이가? 시발! 제하하핳 시발! 발 존나 기네
어메이징시발롬 애송이가? 시발! 댄서 아잇아잇 아잇아잇아잇
무능한남
블블 애송이가? 시발! 발 존나 기네
애송이가? 시발! 제하하핳 애송이가? 시발! 모리 아잇 발 존나 기네
도태딜러
아 재밌었다
```

비교 코드 `아잇아잇`은 `3`, 즉 `<`이다. 따라서 변수 `0`이 `7`보다 작은 동안 값을 출력하고 1씩 증가시켜 `0`부터 `6`까지 출력한다.

반복문은 무한 루프 방지를 위해 최대 1,000,000회까지만 실행된다.

## 현재 제약

- 숫자 리터럴은 음수가 아닌 이진수만 지원한다.
- 문자열의 문자 코드는 유효한 Unicode 범위(`0`~`0x10FFFF`)여야 한다.
- 문자열에서 나눗셈 결과처럼 정수가 아닌 값은 문자 코드로 사용할 수 없다.
- `웨얼 이즈 롤백 넷코드?`는 문자열의 첫 문자와 문자열 밖에서는 사용할 수 없다.
- `else`, 함수, 배열, 주석, 괄호, 논리 연산자는 아직 없다.
